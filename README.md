# 基金会行业2026年会参会助手

这个 Agent Skill 附带年会纯文字版全议程，可用于查找场次、嘉宾、慈善市集和参会指南，或按兴趣安排自己的参会行程。

## 安装

```sh
npx skills add Rae-gu/cff-2026-conference
```

也可以下载仓库 ZIP，解压后将包含 `SKILL.md` 的整个文件夹导入支持 Agent Skills 的助手。

## 试着问问

- 我关注儿童服务和公益资助，帮我挑几场时间不冲突的平行会议。
- 我想逛慈善市集，帮我按展位号找参与机构。
- 我周四下午到银川，几点签到，怎么去会场？

场次时间、地点和参加条件如有更新，以[年会门户](https://ac-2026.cfforum.org.cn/2026/)的公开信息为准。
